# CareHome GRC & ISMS Portfolio

**A practical Governance, Risk and Compliance (GRC) and Information Security Management System (ISMS) portfolio for a fictional UK care-home provider.**

## 1. Project Overview

This project demonstrates how a fictional care-home organisation can identify cybersecurity risks, assess information security controls, document compliance gaps and develop an Information Security Management System (ISMS).

The project focuses on protecting sensitive resident information, managing staff access, strengthening information security governance and improving risk oversight.

## 2. Project Objectives

- Identify and assess information security risks.
- Evaluate selected controls against recognised security frameworks.
- Assess gaps against ISO/IEC 27001:2022 requirements.
- Develop practical security policies and risk treatment recommendations.
- Review user access and accountability.
- Establish an internal audit and management review process.
- Develop a Power BI-ready dataset for GRC reporting.

## 3. Project Scope

### In Scope
- Resident and staff information assets
- User access and identity management
- Information security risks and vulnerabilities
- Security policies and governance
- Supplier and information handling risks
- Internal audit and management review
- GRC metrics and reporting

### Out of Scope
- Testing real healthcare systems
- Accessing real resident or staff records
- Live penetration testing
- Claims of organisational certification or regulatory compliance

## 4. Frameworks and Methodology

- **ISO/IEC 27001:2022** — Information Security Management Systems
- **ISO/IEC 27002:2022** — Information security controls guidance
- **NIST Cybersecurity Framework 2.0** — Cybersecurity risk management
- **Risk-based assessment** — Likelihood, impact, risk treatment and residual risk
- **Evidence-based assurance** — Findings, recommendations and corrective actions

Framework mappings are included where relevant. The project does not claim that all requirements have been independently validated.

This is an educational portfolio project based entirely on a fictional care-home organisation. All users, assets, findings, scenarios and evidence are synthetic.

No real resident information, staff records, credentials or confidential company information should be uploaded.
